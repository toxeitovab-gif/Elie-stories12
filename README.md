# Elite Dental Clinic — сторис по формуле АИДА

Статический сайт: 12 тем сторис, по 4 кадра на тему (Внимание, Интерес, Желание, Действие), всего 48 кадров.
Сборка и зависимости не нужны, достаточно файла `index.html`.

## Размещение на GitHub Pages

1. На github.com нажмите New repository и назовите его, например, `elite-dental-stories`.
2. Нажмите «uploading an existing file» и перетащите `index.html` и `README.md` (при желании и `.nojekyll`).
3. Нажмите Commit changes.
4. Откройте Settings → Pages. В Source выберите «Deploy from a branch», ветку `main`, папку `/ (root)`, нажмите Save.
5. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/elite-dental-stories/`.
